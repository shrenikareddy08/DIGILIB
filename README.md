# DigiLib — Smart Library Management System

DigiLib is a Java-based Smart Library Management System that combines
Data Structures and Algorithms with practical library operations.

## Features

- Book management
- User management
- Book borrowing and returns
- Book searching
- Sorting and organization
- Binary Search Tree
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's algorithm
- Minimum Spanning Tree (MST)
- Dynamic Programming
- Greedy algorithms
- Fenwick Tree
- Segment Tree
- Borrowing analytics
- Smart reading paths
- File-based data storage
